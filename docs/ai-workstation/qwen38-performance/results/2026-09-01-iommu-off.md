# E006 Results: AMD IOMMU Off

Date: 2026-09-01 (America/Chicago)

## Variable Under Test

The Q4_K_M model, ROCm 7.14 runtime, server flags, and benchmark protocol were
held constant. The only intended runtime variable was the kernel parameter:

```text
amd_iommu=off
```

This was a reversible one-boot test. The flag was removed from the saved boot
entry while the test kernel was running, so the following reboot restores the
accepted baseline automatically.

## Boot Evidence

The first reboot selected newly installed kernel `7.1.9-100.fc43.x86_64`
instead of the `7.1.8` entry that had initially been modified. That boot was
not treated as a test. The flag was removed from every entry, added only to the
actual `7.1.9` boot entry, and the host was rebooted again.

The valid test boot showed:

- kernel `7.1.9-100.fc43.x86_64`
- `amd_iommu=off` in `/proc/cmdline`
- zero links under `/sys/kernel/iommu_groups`
- healthy Qwen, LiteLLM, Hermes gateway, and Hermes dashboard services
- only the primary Qwen endpoint listening on port `11440`

Rollback snapshots:

- `/home/helios/.hermes/backups/qwen38-iommu-20260901T231833Z`
- `/home/helios/.hermes/backups/qwen38-iommu-20260901T232227Z`

## Results

| Scenario | Accepted baseline | `amd_iommu=off` |
| --- | ---: | ---: |
| Rust repeat 1 | 11.83 tok/s | 11.83 tok/s |
| Rust repeat 2 | 11.26 tok/s | 11.47 tok/s |
| Code review repeat 1 | 11.21 tok/s | 10.90 tok/s |
| Code review repeat 2 | 11.59 tok/s | 11.57 tok/s |
| Cold context run 1 | 32.88 s | 32.72 s |
| Cold context run 2 | 32.83 s | 32.87 s |
| Cold context run 3 | 32.89 s | 32.92 s |
| Cold context mean | 32.87 s | 32.84 s |

Post-test idle evidence was 1% GPU use, 47 C, about 13.5 W socket graphics
package power, and 22.1 GB decimal GPU memory in use.

## Decision

Reject `amd_iommu=off`. Decode changes were mixed and remained within normal
run variance. The cold-context mean improved by only 0.03 seconds, about 0.1%,
which is not a material or repeatable gain. Keep normal IOMMU behavior for
device isolation and avoid taking on a platform-wide configuration tradeoff
without a demonstrated inference benefit.

## Restoration Evidence

The host was rebooted after the test. Final verification showed kernel
`7.1.9-100.fc43.x86_64` without `amd_iommu=off` in `/proc/cmdline`, 42 restored
IOMMU group links, no failed system units, and healthy Qwen, LiteLLM, Hermes
gateway, and Hermes dashboard services. One Qwen GPU process was present,
using the expected approximately 21.7 GB decimal VRAM at idle.
